How it works

Three steps from image to answer.

  1. Get a key

    Request access below. We look at samples of your captcha first, so we know the API reads it well before you depend on it.

  2. Send the image

    POST the captcha to /v1/solve with your key in the Authorization header. Any language that can make an HTTP request works.

  3. Use the text

    Type text into the captcha field. If confidence is below your cut-off, load a new captcha and try again.

The whole integration

A few lines in the language you already use.

Errors come back as JSON with a stable code you can branch on. The docs list every field, error and limit.

curl -X POST https://captcha.silifton.com/v1/solve \
  -H "Authorization: Bearer $CAPTCHA2TEXT_KEY" \
  -F "image=@captcha.png"
import os, requests

resp = requests.post(
    "https://captcha.silifton.com/v1/solve",
    headers={"Authorization": f"Bearer {os.environ['CAPTCHA2TEXT_KEY']}"},
    files={"image": open("captcha.png", "rb")},
    timeout=15,
)
data = resp.json()
print(data["text"], data["confidence"])
import { readFile } from "node:fs/promises";

const form = new FormData();
form.append("image", new Blob([await readFile("captcha.png")]), "captcha.png");

const res = await fetch("https://captcha.silifton.com/v1/solve", {
  method: "POST",
  headers: { Authorization: `Bearer ${process.env.CAPTCHA2TEXT_KEY}` },
  body: form,
});
const { text, confidence } = await res.json();

Built around your captcha

Every captcha looks different, so we measure yours.

Send us 300 or more of your captchas with their answers. We run them through the API and tell you how many it reads correctly. If that isn't high enough, we train a model on your captcha style and attach it to your API key. Nothing changes in your code.

Reads

  • Text captchas: a word or code drawn on an image
  • Letters, plus digits and other characters on request
  • Warped letters, lines and dots over the text
  • Math captchas like 4 + 3 − 5: send type=math and get the answer, 2

Doesn't read

  • reCAPTCHA, hCaptcha, Cloudflare Turnstile
  • "Select every image with…" puzzles, sliders
  • Audio captchas
